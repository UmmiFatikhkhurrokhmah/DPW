Deskripsi Project

Repository ini berisi hasil praktikum dan latihan mata kuliah Desain Pemrograman Web (DPW) yang disusun berdasarkan modul per pertemuan.
Setiap modul membahas tahapan pembelajaran pengembangan web mulai dari HTML, CSS, JavaScript, PHP, hingga pengolahan database dan CRUD.

Project ini bertujuan untuk:

Memahami struktur dan konsep dasar website
Menerapkan desain tampilan web menggunakan CSS
Membuat interaksi web dengan JavaScript dan jQuery
Mengelola data menggunakan PHP dan database
Mengimplementasikan aplikasi web sederhana

Teknologi Yang digunakan :

HTML5
CSS3
JavaScript
jQuery
PHP
MySQL
XAMPP
